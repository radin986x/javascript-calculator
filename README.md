# 🧮 Vanilla JavaScript Calculator

A lightweight, state-driven web calculator built with raw HTML, CSS, and pure JavaScript. Designed with a focus on core algorithmic logic, robust error handling, and intuitive user experience.

🚀 **Live Demo:** [Click Here to Open Calculator](https://radin986x.github.io/javascript-calculator/)

---

## ✨ Features

- **State-Driven Architecture:** Clean separation of inputs, active operators, and reset operations.
- **Physical Keyboard Support:** Full support for keyboard keybindings (`0-9`, `+`, `-`, `*`, `/`, `.`, `Enter`, `Backspace`, `Esc`).
- **Edge-Case Handling:**
  - Prevents multiple decimal points (`.`) per number operand.
  - Handles division-by-zero errors gracefully.
  - Multi-digit backspace support.
- **Zero Dependencies:** Pure Vanilla stack without external libraries or frameworks.
